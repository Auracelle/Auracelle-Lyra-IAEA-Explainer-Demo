# Auracelle Lyra — IAEA Explainer

A narrated, self-contained walk-through that explains **Auracelle Lyra** to safeguards inspectors before they use the full simulation.

Lyra is an asynchronous decision-support environment for safeguards verification. It lets inspection teams rehearse procedures against an adaptive Agentic AI Red Team, and score treaties, policies and workflows with confidence levels, before those procedures and documents are tested in the field.

> **This repository contains the Explainer only.** It explains Lyra; it is not the simulation. Nothing in it asks the viewer to type, upload or decide anything.

## View it

- **Online:** open the GitHub Pages link for this repository.
- **Offline:** download `index.html` and open it in any modern browser. No installation, build step or internet connection is needed.

On the opening screen, choose **Begin with audio** or **Read without audio**.

| Control | What it does |
|---|---|
| ▶ Play / ⏸ Pause | Start or pause narration (or press the space bar) |
| ◀ Back / Next ▶ | Move between the 14 chapters (or press the arrow keys) |
| Audio on / off | Switch between narration and captions only |
| Speed | Cycle through 1×, 1.15× and 0.9× |
| Auto-advance | Move to the next chapter when narration ends |

The full tour takes about ten minutes.

## Chapters

1. Welcome
2. Why Lyra — what grey-zone pressure reaches first
3. Harmonization — many domains, one frame, with nuclear running through all of them
4. How a session works — scenario, role, rounds
5. What you see — the state of the system from your role's point of view
6. Your move — every move needs an argument
7. Agentic AI Red Team — an adversary that adapts to you
8. The core question — interference or non-compliance? *(inspector edition, in development)*
9. The human dimension — the pressure inspectors carry in *(inspector edition, in development)*
10. The cascade — how one gap travels
11. Adjudication and evidence — a decision trail you can audit
12. Scoring with confidence — every score comes with a confidence level
13. Boundaries — what Lyra is, and is not
14. Next steps — walk through, rehearse, calibrate

## Privacy

- The page makes **no network requests**. A Content Security Policy in the file blocks all outside connections, including fonts, images, scripts and analytics.
- It uses **no cookies, local storage or tracking**, and collects no data.
- Narration uses the **browser's built-in speech voice**, so no audio is downloaded or streamed.

## Browser support

The Explainer works in current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile.

Narration quality depends on the voices installed on the device. It sounds best in Chrome or Edge, or on macOS and iOS. If a device has no speech voice, the Explainer falls back to captions that advance on a timer.

## Accessibility

- Captions for all narration, highlighted sentence by sentence
- Full keyboard control
- Honours the operating system's **reduce motion** setting
- Layout adapts to phone, tablet and desktop screens

## Publish on GitHub Pages

1. Create the repository and add `index.html`, `README.md`, `SECURITY.md` and `LICENSE` to the root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site appears at `https://<account>.github.io/<repository>/` within a few minutes.
